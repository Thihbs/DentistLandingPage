# Clínica Thais Yamamoto

Esta aplicação é uma landing page desenvolvida em Angular para apresentar os serviços da Clínica Thais Yamamoto. Aqui você encontra informações sobre a equipe, especialidades oferecidas e a localização do consultório.

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
   Depois, acesse `http://localhost:4200/` no navegador.

## Build para produção

Para gerar os arquivos otimizados em `dist/` execute:
```bash
npm run build
```

A versão de produção pode ser servida por qualquer servidor HTTP estático.
